# Business Scenario

## Background

ABC Retail Pvt Ltd has successfully automated the build process of its Java application using Jenkins and Maven.

Although every code commit is compiled automatically, the **Quality Assurance (QA)** team has identified a significant risk: code is being packaged and delivered without validating whether the application still behaves correctly.

To improve software quality, the organization has adopted a **Continuous Testing** strategy. Every Jenkins build must execute automated **JUnit** tests before packaging the application.

If any critical test fails:

* The Pipeline must stop.
* Developers should immediately know which test failed.
* Test reports should be published in Jenkins for review.
* Historical test results should be available for trend analysis.

As the DevOps Engineer, your task is to extend the existing Jenkins Pipeline by integrating automated unit testing and publishing JUnit reports.

# Troubleshooting Guide

| Issue                               | Possible Cause                    | Resolution                                                           |
| ----------------------------------- | --------------------------------- | -------------------------------------------------------------------- |
| No tests executed                   | Test classes not detected         | Verify naming conventions and test directory structure               |
| `No test report files were found`   | Incorrect report path             | Confirm the Surefire XML files exist under `target/surefire-reports` |
| Build fails during `mvn test`       | Test failure or compilation issue | Review the Console Output and correct the failing test               |
| Test reports not visible in Jenkins | `junit` step missing or incorrect | Verify the report path supplied to the JUnit step                    |
| Surefire reports missing            | Maven test phase skipped          | Ensure `mvn test` executes successfully before publishing reports    |
