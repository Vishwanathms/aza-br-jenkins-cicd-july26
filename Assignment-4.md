# Home Assignment 4 – End-to-End CI/CD Pipeline using Jenkins, Docker & Amazon ECR + JAVA BASED CODE 

## Objective

Design and implement a Production-Style Continuous Integration and Continuous Deployment (CI/CD) pipeline using Jenkins, Docker, and Amazon Elastic Container Registry (ECR).

This assignment focuses on building, testing, containerizing, and publishing an application image to Amazon ECR through a fully automated Jenkins Pipeline.

> **Note:** Deployment to an AWS EC2 instance is **not** part of this assignment.

---

# Learning Outcomes

After completing this assignment, students will be able to:

-- Application should be spring boot, postgresql

- Configure Jenkins for CI/CD
- Integrate GitHub with Jenkins
- Build Java applications
- Execute automated unit tests
- Build Docker images
- Authenticate Jenkins with AWS
- Push Docker images to Amazon ECR
- Implement production-grade Jenkins Pipelines
- Configure email notifications
- Validate Docker images stored in Amazon ECR
